/* Pointer */
----------------------------------------------------------------------------------------------------------------------
In order to keep the code safe everything is "locked". So in order to be able to use pointers one have to declare
the code "unlock(what?)".

There are multiple unlocks.
    Now:
        pointers
        raw_pointers
        memory
        casting
        arithmetic
        bounds
        threads
        ffi

    Later:
        pointer_arithmetic,
        transmute
        reflection
        filesystem
        network
        kernel

unlock(pointers, memory, arithmetic){
    ~x = 42                             #Mutable(Variable/changeable) 64bits Integer
    ptr: *i64 = &~x                     #Point to the memory address of ~x (declaration)
    ptr* = ~x + 72                      #Write the value 100 to ptr (write)
    ~x = ptr*                           #Set the value of ~x with ptr (read)
}

/* Functions */
----------------------------------------------------------------------------------------------------------------------

fn add(a: i32, b: i32) -> i32?
    ~c = a + b

Let's deconstruct this function.

fn      - Declares a function.
add     - Function name.
()      - Function parameters.
a: i32  - Immutable 32-bit signed integer.
b: i32  - Immutable 32-bit signed integer.
->      - Declares the return type.
i32     - Returns a 32-bit signed integer.
?       - Error propagation suffix. Indicates that the function may return an error and allows nested errors to bubble up safely.
~c      - Mutable local variable.
+       - Addition operator.
